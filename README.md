ЗДЕСЬ БУДЕТ ВСЯ ИНФОРАЦИЯ ПО ПРОЕКТУ UE И ПО ГЕЙМДЖЕМУ

Информация по структуре Unreal Engine:
  1. Версия 5.8.0
  2. Структура папок проекта:
     1. Blueprints/ — сюда складывайте всю общую логику, например, виджеты, интерактивные объекты.
     2. Characters/ - папка, где находятся все для персонажей, меши, анимация, текстуры и тд.
     3. Maps/ - папка для всех карт (уровней).
     4. Environment/ - всё, что стоит на уровне: стены, полы, камни, деревья, ящики.
     5. UI/ — сюда текстуры и шрифты, а сами виджеты — в Blueprints/UI/.
     6. Audio/ - папка для всех звуковых ассетов.
     7. Materials/ — только общие материалы. Материалы конкретного персонажа или объекта лучше держать рядом с ним.
  3. "Стилистика письма":
     1. Префиксы Unreal: BP_ (Blueprint), WBP_ (Widget Blueprint), SM_ (Static Mesh), SK_ (Skeletal Mesh), M_ (Material), MI_ (Material Instance), T_ (Texture), A_ (Animation), AM_ (Animation Montage), ABP_ (Anim Blueprint).
     2. Именование: классы MyClass, переменные MyVariable, булевы bIsReady, функции MyFunction().
